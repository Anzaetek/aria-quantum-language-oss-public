# Fermionic examples

OpenQASM 2 circuits, FermionicQASM programs, and OpenFermion ladder
operators. The QASM2 files run through `omega-run --expectation-fermionic`.
The `.fqasm` files are FermionicQASM 1.0; LiH passes its Hamiltonian
with `--hamiltonian`. They are not `.aria` files: the Aria grammar has
no fermionic observable, and the application harness is qubit-shaped.
Do not rewrite these as `.aria`. The QASM2 files stay.

The numbers, the papers, and what each check cannot see are in
[`docs/FERMIONIC_EXAMPLES.md`](../../docs/FERMIONIC_EXAMPLES.md).

| files | what | reference |
|---|---|---|
| `h2_hf.qasm`, `h2_ground.qasm`, `h2_op.txt` | H₂/STO-3G at 0.7414 Å, Hartree–Fock and the one-parameter ground state | OpenFermion's shipped MolecularData file |
| `h2_hf.fqasm`, `h2_ground.fqasm` | the same two states in FermionicQASM. `h2_ground.fqasm` is UCCSD at the pinned angle | the QASM2 twin and the same OpenFermion energies |
| `hubbard2.qasm`, `hubbard2_op.txt` | 2-site Fermi–Hubbard, t = 1, U = 4, two-electron ground energy | closed form 2 − 2√2, and OpenFermion `fermi_hubbard` in that sector |
| `hubbard2.fqasm` | the same ground state in FermionicQASM | the QASM2 twin and 2 − 2√2 |
| `kitaev_n2.qasm`, `kitaev_n8.qasm`, `kitaev_n64.qasm` and their operators | Kitaev chain at t = Δ = 1, μ = 0, energy −(N−1) | closed form; statevector at N = 2 and N = 8. N = 64 is the analytic value and majoranaprop's own certificate |
| `kitaev_n2.fqasm` | the N = 2 one-particle ground state. N = 8 and N = 64 are not in this gate set | energy −1, shared with `kitaev_n2.qasm`; amplitudes 1/√2 at indices 1 and 2 |
| `lih_hf.fqasm`, `lih_sto3g.fcidump` | LiH/STO-3G at 1.6 Å, the RHF determinant | PySCF RHF. PySCF FCI is the ground-state number this circuit does not reach |

`h2_op.txt` is regenerated by `tools/fermionic_examples/gen_h2_op.py`
from that file. The script does not call PySCF.
